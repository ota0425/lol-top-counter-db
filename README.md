# LoL 対面対策DB

公開サイト：**https://ota0425.github.io/lol-top-counter-db/**

キショオタch「家族でイッキ見！バカでもわかる対策まとめ.top」の日本語自動字幕を基に、チャンピオン別の対策を検索するローカルWebアプリです。

- 対象動画：https://www.youtube.com/watch?v=gmuF58MD3ts
- 71チャンピオンのまとめ画面を転記した355項目と、追加の対策58件、詳しい説明286件を収録しています。
- 最初のTOPまとめ動画に加え、同じチャンネルの個別対策動画21本を収録。TOP・MID向けの対策を検索できます。
- チェックリストは各チャプターのまとめ画面を目視して転記し、アイコン部分をスキル・ルーン・装備の名称に置き換えました。スラッシュや区切りの空白は読みやすく統一しています。
- 追加の対策と詳しい説明は、本編の日本語自動字幕を基に整理しています。試合実況の全発言を対策として網羅したものではありません。
- 355項目の見出しは映像と照合済みです。追加の対策・詳しい説明には自動字幕の誤認識を含む可能性があります。最初のまとめ動画は2025年9月公開です。個別動画も含め、現行パッチへの適合は確認していません。

## 起動（Windows PowerShell）

このフォルダで次を実行します。

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

次回からは最後の1行だけで起動できます。ブラウザで `http://localhost:8501` を開きます。

PythonとStreamlitがすでに使える場合：

```bash
python -m streamlit run app.py
```

## 使い方

1. 「対策を検索」にチャンピオン名を入力します。部分一致、日本語・ひらがな・半角カナ・英語名に対応しています。例：`カミール`、`かみーる`、`Camille`。`カ・サンテ`、`ドクター・ムンド`等の別表記でも検索できます。
2. 検索結果では、まずまとめ画面の5項目と「追加の対策」を表示します。「詳しい立ち回り・補足」から詳しい説明も読めます。出典・字幕・確認状況は表示しません。
3. 収録済みの対策と動画で確認済みの手入力ノートを検索できます。
4. 「対策を登録・確認」で内容・分類・時刻を編集し、実際に動画で確かめたものを「確認済み」にします。出典時刻はそのチャンピオンのチャプター内で指定します。
5. 手入力の未確認ノートは検索に表示しません。確認済みへの変更後に表示されます。
6. 「字幕・チャプターを取り込む」でSRT/VTTやバックアップJSONを取り込めます。通常は収録済みのデータですぐ検索できるため、初期登録は不要です。

## データとバックアップ

- SQLite DBは `counters.sqlite3` です。停止した状態でコピーすれば字幕を含めてバックアップできます。
- 対策とチャプターは「対策を登録・確認」からJSONでエクスポート・復元できます。JSONには字幕は含めません。同じ内容の対策は重複追加せず、既存の確認状況やチャプター時刻を維持します。
- `data/counters.json`：各チャンピオンの `checklist`（5項目）、`supplements`（追加の対策）、`tips`（詳しい説明）。管理用の時刻も保存しています。公開画面では時刻や出典を表示しません。
- `data/transcript.ja.json`：ローカル環境の任意の字幕ファイル。公開リポジトリには含めません。存在しなくても検索アプリは起動します。
- `data/source.json`：最初のまとめ動画の情報と概要欄由来のチャプター時刻。
- `data/sources.json`：収録動画22本のURL・タイトル・チャンネル・対応チャンピオン。公開画面に出典は表示しません。
- 各チャンピオンの `video_url` と時刻をセットで保存し、別動画の字幕や出典が混ざらないようにしています。
- 初回起動時に同梱データを読み込みます。その後の編集・削除は再起動しても維持します。既存DBにはチェックリストと追加の対策だけを追加し、編集済みのノートを上書きしません。
- アプリの利用中に外部AI APIへの送信や字幕の再取得は行いません。

## 開発時の検証

```bash
python3 -m unittest discover -s tests -v
python3 -m streamlit run app.py
```

DB処理は `db.py`、画面は `app.py` です。追加のAPIキーや有料サービスは不要です。

## GitHub Pagesでの公開

公開版は `docs/index.html` です。対策の検索に対応し、出典・字幕・確認状況は表示しません。編集機能はローカルのStreamlitアプリで利用できます。

生成し直す場合：

```bash
python3 scripts/build_site.py
```

ローカルDBで編集した内容を反映する場合：

```bash
python3 scripts/build_site.py --database counters.sqlite3
```

更新した `docs/index.html` をGitHubへ反映すると、GitHub Pagesが再公開します。公開設定は `main` ブランチの `/docs` です。公開ページは自動字幕やSQLiteのDBファイルを配信しません。

まとめ画面と本文の装備アイコンが異なる箇所（ウディアの5項目目）は画面の表記を維持し、本文で説明されているスイフトネスブーツを補足しています。

## アイコン

スキル・パッシブ・サモナースペル・アイテム・ルーンは、[Riot公式Data Dragon](https://developer.riotgames.com/docs/lol#data-dragon)のアイコンを使っています。動画の時期に合わせて原則バージョン `15.17.1` に固定し、404画像を `docs/assets/icons/` に同梱しています。そのバージョンに存在しないザーヘンには `16.22.1` の画像を使用しています。利用時にRiotのサーバーへ画像を取りに行く必要はありません。

対応表は `data/icons.json`、取得用スクリプトは `scripts/sync_icons.py` です。取得し直す場合は `python3 scripts/sync_icons.py`、サイトの再生成は `python3 scripts/build_site.py` を実行します。

チェックリスト内のスキル記号にはその対面チャンピオンのアイコンを表示します。他チャンピオンのスキルが登場する補足では、誤対応を避けるためスキル記号の自動置換を行いません。補足の装備・ルーン名にはアイコンを表示します。

## 今回追加したチャンピオン

グラガス、オリアナ、ルブラン、ツイステッド・フェイト、サイラス、ヴェックス、ビクター、ヴァルス、イレリア、アニビア、アジール、タロン、アーリ、ハイマー、ガリオ、ザーヘン、マルザハール、メル、カタリナ、ゼド、アクシャン。

同名の対策動画が複数ある場合は、新しいリメイク版を優先しています。取得した追加字幕はローカルの `data/transcripts/` に保存し、公開リポジトリには含めません。既存DBは初回起動時に一度だけ新規チャンピオンを追加し、既存ノートの編集・削除は維持します。
